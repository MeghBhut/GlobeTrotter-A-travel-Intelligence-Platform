========================================================================
CYANOTYPE THEME — IMPLEMENTATION PACKAGE
Travel site theme: light + dark, cyan primary / warm gold secondary
========================================================================
Hand this file to a frontend dev. It contains, in order:
  1. <head> snippet (fonts + anti-flash theme script)
  2. Theme tokens CSS (light default, dark via [data-theme="dark"])
  3. Base type rules mapped to font roles
  4. Component CSS mapped to tokens (nav, hero, search, cards, chips,
     buttons, prices/ratings, postcard image band, theme toggle)
  5. Theme toggle JS (vanilla, drop-in)
  6. Markup contract (class names the CSS expects)
  7. Acceptance checklist to verify before shipping

Everything downstream keys off CSS custom properties. No component
file should contain a raw hex value — reference a var(--token) or a
value derived from one.

1) <HEAD> SNIPPET — fonts + no-flash theme init
   Paste inside <head>, BEFORE any stylesheet that paints color/bg.

<!-- Cyanotype: theme init (must run before first paint, no flash) -->
<script>
  (function () {
    try {
      var saved = localStorage.getItem('cyanotype-theme');
      var theme = saved
        ? saved
        : (window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
      if (theme === 'dark') {
        document.documentElement.setAttribute('data-theme', 'dark');
      }
    } catch (e) {
      /* localStorage unavailable (privacy mode, etc.) — fall back to light */
    }
  })();
</script>

5) THEME TOGGLE JS — vanilla, drop in a script file (e.g. theme.js)
   The <head> snippet in section 1 only handles the pre-paint read.
   This handles the click-to-toggle + persistence + icon swap.
========================================================================

(function () {
  var STORAGE_KEY = 'cyanotype-theme';

  function getStoredTheme() {
    try {
      return localStorage.getItem(STORAGE_KEY);
    } catch (e) {
      return null;
    }
  }

  function setStoredTheme(theme) {
    try {
      localStorage.setItem(STORAGE_KEY, theme);
    } catch (e) {
      /* ignore write failures (private browsing, quota, etc.) */
    }
  }

  function currentTheme() {
    return document.documentElement.getAttribute('data-theme') === 'dark'
      ? 'dark'
      : 'light';
  }

  function applyTheme(theme) {
    if (theme === 'dark') {
      document.documentElement.setAttribute('data-theme', 'dark');
    } else {
      document.documentElement.removeAttribute('data-theme');
    }
    updateToggleIcons(theme);
  }

  function updateToggleIcons(theme) {
    document.querySelectorAll('[data-theme-toggle]').forEach(function (btn) {
      btn.setAttribute('aria-pressed', theme === 'dark' ? 'true' : 'false');
      btn.setAttribute(
        'aria-label',
        theme === 'dark' ? 'Switch to light mode' : 'Switch to dark mode'
      );
    });
  }

  function toggleTheme() {
    var next = currentTheme() === 'dark' ? 'light' : 'dark';
    applyTheme(next);
    setStoredTheme(next);
  }

  document.addEventListener('DOMContentLoaded', function () {
    // sync icon state with whatever the anti-flash head script already set
    updateToggleIcons(currentTheme());

    document.querySelectorAll('[data-theme-toggle]').forEach(function (btn) {
      btn.addEventListener('click', toggleTheme);
    });
  });

  // keep in sync if user changes OS theme and hasn't chosen manually
  if (window.matchMedia) {
    window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', function (e) {
      if (!getStoredTheme()) {
        applyTheme(e.matches ? 'dark' : 'light');
      }
    });
  }
})();

7) ACCEPTANCE CHECKLIST — verify before shipping
========================================================================

[ ] No #000 / #FFF / rgb(0,0,0) / rgb(255,255,255) anywhere in CSS
[ ] No raw hex codes in component files — everything is var(--token)
[ ] Body text (--ink on --bg / --surface) passes 4.5:1 contrast in
    BOTH light and dark (spec values verified: light ink #16262B on
    bg #D7E0E2 ≈ 11.9:1; dark ink #D3E0E1 on bg #101E20 ≈ 12.6:1)
[ ] Reload the page in dark mode — confirm zero flash of light theme
[ ] Toggle theme, reload — confirm the choice persisted via
    localStorage key "cyanotype-theme"
[ ] Cyan (--cyan) appears only on: links, nav active state, primary
    buttons, chips, eyebrow labels — never on prices/ratings
[ ] Gold (--sun) appears only on: prices, ratings, sun graphic —
    never on buttons/links/nav
[ ] Headings use Bricolage Grotesque; body/UI uses Hanken Grotesk;
    meta/price/date/eyebrow use Spline Sans Mono
[ ] Cards: 9–10px radius. Buttons/inputs: 7px radius. Chips: 20px
    (pill) radius
[ ] Postcard placeholder shows sky band over sea band with a small
    circular sun — used only where no real photo exists
[ ] Focus states visible on inputs, buttons, and chips (keyboard nav)
